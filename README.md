# marlin-artes

Hospedagem pública e temporária das artes e vídeos que a **Bia** (Cérebro do Studio · Marlin Tattoo) publica no Instagram.

- O Instagram só aceita mídia por link público, então cada arte/vídeo é colocado em `midia/<dia>/` logo antes de postar.
- Link usado: `https://raw.githubusercontent.com/marlonsilva2421-sys/marlin-artes/main/midia/<dia>/<arquivo>`
- Arquivos com mais de 3 dias são apagados automaticamente (o Instagram já guardou a cópia dele).
- Não coloque nada privado aqui: o repositório é público.
